| 安全移动引擎 | `core/organizer.py` | `plan → 预览 → move_items → 撤销` 已闭环，**任何新功能都应复用** |

## 二、三条主线

### 主线 A — 把「整理」这一件事做深（护城河）
整理是唯一上线的核心，也是用户真正的痛点。深挖它比铺新功能更划算。

### 主线 B — 兑现 Feature Registry 的承诺（快速拉满"功能数"）
重复文件查找 / 空文件夹清理 / 批量重命名 / 快速搜索 / 文件夹分析 —— 全是**低风险、可复用现有引擎**的功能。

### 主线 C — 平台化与自动化（从"工具"变"习惯"）
定时整理 / 开机整理 / 托盘常驻 / 右键菜单 —— 让工具**主动出现**，而不是等用户打开。

## 三、功能候选池（含实现要点）

### 🟢 快速见效（Quick Wins，1–3 天级）

#### 1. 空文件夹清理（`EMPTY_FOLDER`，已 COMING_SOON）
- **价值**：用户对"干净"的感知极强，实现极简。
- **要点**：复用 `scanner`，筛 `is_dir() and not any(iterdir())`；**递归自底向上**判断（子目录清空后父目录才变空）。动作是**移动到隔离区或直接删除**——建议默认"移到回收站"而非 `rmtree`，并预览。
- **风险**：低。注意排除系统目录（`System Volume Information` 等）。

#### 2. 文件夹分析（`FOLDER_ANALYZER`，PLANNED）
- **价值**：给出"空间去哪了"的可视化，是"大文件分析"的自然升级。
- **要点**：复用 `ScanResult.sizes`；按子目录聚合做**树图 / 占比条形**；纯只读，零风险。
- **风险**：极低。UI 用 QPainter 自绘即可（项目已有 `ScoreRing` 自绘先例）。

#### 3. 导出整理报告（README §8.2 已列）
- **价值**：让"整理成果"可留档、可分享（微信发给朋友 → 天然传播）。
- **要点**：`history` + `operations` 已有全部数据，生成 HTML / CSV；HTML 报告可内嵌整洁度评分 + 分类饼图。
- **风险**：极低。纯读取。

#### 4. 大文件页增强（已有页面）
- **要点**：Top N 可调（现固定 100）、按类型聚合筛选、支持"移到回收站"（**必须二次确认 + 走系统回收站 API，绝不 `rm`**）、右键"打开所在位置"已有。
- **风险**：低（删除动作需严格确认）。

#### 5. 深色/浅色跟随系统 + 主题微调
- **要点**：读 Windows 注册表 `AppsUseLightTheme` 决定初始主题。
- **风险**：极低。

---

### 🟡 中期价值（1–2 周级）

#### 6. 重复文件查找（`DUPLICATE_FINDER`，COMING_SOON）
- **价值**：释放磁盘空间感知最强，是存储类功能的"旗舰"。
- **要点**：三阶段漏斗——**① 按 size 分桶**（唯一 size 直接排除）→ **② 读头部 4KB 比对**（快速排除）→ **③ 全文件 SHA-256**（确认）。复用 `update/integrity.sha256_bytes`。结果按"每组保留 1 个"给出预览，动作**只移动到隔离区/回收站**，绝不直接删。
- **风险**：中。大目录全量哈希较慢 → 必须后台线程 + 进度条（`Worker` 已具备）；需防"删了唯一副本"→ 强制每组至少保留一个。

#### 7. 批量重命名（`BATCH_RENAME`，COMING_SOON）
- **价值**：摄影/素材/下载党刚需。
- **要点**：模板引擎（`{name}_{序号}`、`{日期}_原名`、大小写、查找替换、正则）；**实时预览新旧对照表**；执行前落 `pending`，支持一键撤销（复用 `operations` 表范式，新增 operation type）。
- **风险**：中。命名冲突、非法字符、超长路径都要处理（`win_long` 已就绪）。

#### 8. 整理方案自定义 / 规则可视化编辑（README §8.2 已列）
- **价值**：把"8 类固定规则"升级为"我的规则"，差异化竞争力。
- **要点**：`settings` 表存用户规则 JSON（`ext → category`），`classifier` 已支持传入 `rules` 参数——**改造点极小**；UI 提供拖拽式规则编辑器 + "自定义目标目录"。
- **风险**：低。

#### 9. 定时整理 / 开机整理（`SCHEDULED_CLEAN` / `STARTUP_CLEAN`，PLANNED）
- **价值**：从"手动工具"变"自动习惯"，留存关键。
- **要点**：Windows **任务计划程序**（`schtasks`）注册一个调用 EXE 的静默整理任务；或应用内 QTimer + 托盘常驻。**开机整理务必"只预览不自动移动"**，避免用户开机时文件被悄悄移动。
- **风险**：中高。涉及系统级注册，需可一键卸载/停用；自动化移动文件需极克制的默认策略。

### 🔴 战略级（1 个月+，需要单独阶段）

#### 10. 资源管理器右键菜单「用 Desktop Cleaner 整理此文件夹」
- **价值**：把工具塞进用户最高频的入口，获客/留存利器。
- **要点**：注册表 `HKCU\Software\Classes\Directory\shell`；参数传目录路径；EXE 支持命令行参数直接进入整理流程。
- **风险**：中（注册表写入需可干净卸载；注意杀软误报）。

#### 11. 系统托盘常驻 + 一键整理桌面
- **要点**：`QSystemTrayIcon`；托盘菜单"整理桌面 / 还原最近 / 打开主界面"。
- **风险**：低。

#### 12. 自动更新 Option A（下载 + SHA256 + 替换）
- **现状**：`update/integrity.py` 原语已就绪，V1.1 只"检查不下载"。
- **要点**：下载到临时文件 → 校验 manifest SHA256 → **校验 Authenticode 签名** → 写 `.bat` 延迟替换自身 → 重启。**必须先上代码签名**，否则 SHA256 只能防传输损坏、防不了篡改。
- **风险**：高。自替换是崩溃高发区，必须分阶段灰度。

#### 13. 代码签名 + SmartScreen 声誉
- **价值**：消除"未知发布者"红色警告——**对非技术用户是信任门槛**。
- **要点**：EV 代码签名证书（可立即获 SmartScreen 信任）或 OV + 声誉积累；`build.bat` 已预留 `signtool` 位。
- **风险**：成本（证书费用）+ 流程。

#### 14. 本地诊断包导出（不上传）
- **要点**：把 `data/desktop_cleaner.log` + DB 摘要 + 环境信息打包为 zip，用户主动发送。**坚持完全本地原则，不做静默上报**。
- **风险**：低。注意脱敏（路径可能含用户名）。

#### 15. 多语言 i18n
- **要点**：现在文案硬编码中文。抽 `tr()` + Qt Linguist。若只做国内用户可暂缓。
- **风险**：低但工作量大（全量文案抽取）。

## 四、优先级矩阵（价值 × 成本）

```
高价值 ┤  空文件夹清理      重复文件查找        自动更新(Option A)
       │  文件夹分析        批量重命名          代码签名
       │  导出报告          定时/开机整理       右键菜单
       │  大文件增强        自定义规则
低价值 ┤  深色跟随系统      多语言              智能分类(AI)
       └──────────────────────────────────────────────
          低成本            中成本              高成本
```

**推荐排期**：
- **v1.2（低成本高价值）**：空文件夹清理 → 文件夹分析 → 导出报告 → 大文件页增强 → 自定义规则。**5 个功能，全部复用现有引擎，风险可控。**
- **v1.3（中成本）**：重复文件查找 → 批量重命名 → 托盘常驻 → 右键菜单。
- **v2.0（战略）**：代码签名 → 自动更新 Option A → 定时/开机整理 → 多语言。

## 五、必须守住的坑（安全底线）

1. **任何"删除"都要经过系统回收站**，绝不 `os.remove` / `shutil.rmtree` 直接删用户文件。空文件夹、重复文件、大文件清理都适用。
2. **任何"批量移动/改名"都要先预览、可撤销**，并复用 `pending` 两阶段落库 + 启动对账。
3. **自动化功能（定时/开机）默认"只预览不执行"**，让用户显式开启自动移动。
4. **AI/云端能力必须显式授权**，且不得与"完全本地、数据不上传"的产品承诺冲突；优先本地推理。
5. **系统级集成（右键菜单、任务计划、托盘）必须可一键干净卸载**。
6. **重复文件查找必须保证每组至少保留一份**，绝不能让用户删掉唯一副本。

## 六、一句话建议

> 与其新增第 11 个"规划中"的功能，不如把 `features.py` 里**已经对用户承诺过的 10 个功能兑现掉**——尤其是**空文件夹清理、文件夹分析、导出报告**这三个"低成本高感知"的，它们能复用现有引擎、几乎不引入新风险，却能让产品立刻显得"完整"。
