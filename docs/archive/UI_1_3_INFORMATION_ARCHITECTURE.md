## 3. 新 IA（推荐）

### 3.1 导航（收敛为任务导向，去概念页）

```text
整理          ← 首页/整理合一或并列为"整理"（核心任务入口）
历史
设置
```
- **移除** `更多工具` 导航项（概念预告）。
- **重命名** `智能整理` → `整理`。
- **首页与整理的关系**：保留"首页"作为着陆（文件夹优先 Hero + 最近整理 + 撤销），"整理"页为完整配置/扫描/预览工作台。两者均指向同一核心任务，不制造割裂。

### 3.2 命名映射表（全局替换）

| 原 | 新 | 位置 |
|---|---|---|
| 智能整理 | 整理 | `sidebar.py` / `app_shell.py` / `organize_page.py` / `history_page.py` 空状态 |
| 更多工具 | （移除）/ 若保留路线图→"计划功能"（置于关于内静态文本） | `sidebar.py` / `dashboard_page.py` / `tools_page.py` |
| 整理方案（custom） | 接回为"整理"内的"整理方式"分段，或保留为二级但可达 | `custom_page.py` |
| 让数字空间焕然一新 | 选择整理方式，整理前可预览 | `custom_page.py:90` |

### 3.3 模式选择（类型/日期）归宿
- **方案 A（推荐）**：保留 `custom_page` 作为"整理方式"设置页，并**重新加入导航**（命名"整理方式"或并入"设置"）；同时 `organize_page` 内已有 `Segmented` 模式选择（`:108`），两者共用 `settings_repo["mode"]`，不产生冲突。
- **方案 B**：删除 `custom_page`，模式选择完全收口到 `organize_page` 的 `Segmented` + `settings_page` 的"默认整理方式"。更简洁，但需确认 `test_appshell` 对 `CustomPage` 存在的断言（见迁移计划风险项）。

### 3.4 首页重新定义（§5 folder-first）

```text
Desktop Cleaner
整理文件

选择一个文件夹开始扫描

┌───────────────────────────────────────┐
│ 文件夹                                 │
│ C:\Users\...\Desktop                   │
│                              选择文件夹│
└───────────────────────────────────────┘
                [ 扫描 ]

最近整理（真实数据，非装饰指标）
───────────────────────────────────────
今天 10:42    Desktop       18 个文件
昨天 16:21    Downloads     32 个文件

[ 撤销最近一次整理 ]   ← 若存在可撤销记录
```
- **第一焦点**：文件夹选择 + 扫描（已满足，保留）。
- **移除**：整洁度圆环（装饰指标，根因 3）。
- **移除**："发现更多工具 →"入口。
- **保留**：最近整理摘要（真实历史，比整洁度更有用）、撤销入口。

### 3.5 设置 / 关于 / 更新 归属

| 区块 | 内容 | 归属 |
|---|---|---|
| 常规 | 深色模式、默认整理方式、包含子文件夹 | 设置页 |
| 更新 | 检查更新、自动检查开关 | 设置页（已有） |
| 关于 | 版本、版权、功能简述（去 emoji） | 关于弹窗 |
